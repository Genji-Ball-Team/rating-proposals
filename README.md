# Rating proposals

How the EU ranked leaderboard and tiers would look under each proposed rating change, replayed over every ranked match up to 2026-10-23. A simulation, not the live ratings: those are on [genjiball.us](https://genjiball.us/).

Static page for GitHub Pages: `index.html`, `app.js`, `style.css` (from genjiball-ranked) and `data.json` (made by the replay script).
