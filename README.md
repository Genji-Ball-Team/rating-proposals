# Rating proposals

How the EU ranked leaderboard and tiers would look under each proposed rating change, replayed over every ranked match from launch (2026-10-05, legacy v1.3.2 logs left out) up to 2026-10-23, and scored with a train / choice / test split by time. A simulation, not the live ratings: those are on [genjiball.us](https://genjiball.us/).

Static page for GitHub Pages: `index.html`, `app.js`, `style.css` (from genjiball-ranked) and `data.json` (made by the replay script, `.scratch/placement/site.ts` in the team workspace).
